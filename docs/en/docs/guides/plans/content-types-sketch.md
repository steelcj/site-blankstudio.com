## Default Content Types

Includes these default content types provided by `uc.app.contenttypes`:

| Type           | Description                                  |
| -------------- | -------------------------------------------- |
| **Folder**     | Container for organizing other content items |
| **Page**       | Standard web page content                    |
| **News Item**  | Blog-like news articles                      |
| **Event**      | Calendar events with start/end dates         |
| **File**       | Binary file uploads                          |
| **Image**      | Image files with display properties          |
| **Document**   | Rich text documents                          |
| **Collection** | Dynamic queries/lists of content             |

## Key Concepts

- **Containers vs Items**: Content types are either containers (holding other items) or items (leaf nodes)
- **Schema-based**: Each type has a schema defining its fields
- **Content type framework**: For content type development
- **Behaviors**: Reusable features that can be added to content types (e.g., publishing dates, tags, relations)
